# راهنمای سایت پورتفولیو (فارسی)

این سند برای این ساخته شده که شما (صاحب سایت) بتوانید بدون نیاز به دانش عمیق برنامه‌نویسی،
متن‌ها، رنگ‌ها، لینک‌ها و تنظیمات سایت را پیدا و ویرایش کنید. هر بخش زیر می‌گوید
«کجا باید دنبال چه چیزی بگردید».

> این پروژه با React + TanStack Start + Tailwind CSS نوشته شده و از فایل `src/contexts/LanguageContext.tsx`
> برای دوزبانه بودن (فارسی/انگلیسی) استفاده می‌کند.

---

## ۱. اولین کارها قبل از انتشار سایت

### ۱.۱. ایمیل واقعی خود را ثبت کنید (ضروری)

فایل: `src/config/contact.ts`

مقدار `CONTACT_EMAIL` فعلاً یک placeholder (`your-email@example.com`) است.
آن را با ایمیل واقعی خودتان جایگزین کنید — همین یک تغییر، در همهٔ بخش‌های سایت
(فوتر، بخش تماس، Command Palette، Hero) به‌طور خودکار اعمال می‌شود.

```ts
export const CONTACT_EMAIL = 'ایمیل-واقعی-شما@example.com';
```

### ۱.۲. لینکدین

همان فایل `src/config/contact.ts`، مقدار `LINKEDIN_URL` را در صورت نیاز تغییر دهید.

## ۲. ساختار کلی پوشه‌ها

```

  contexts/
    LanguageContext.tsx  ← تمام متن‌های سایت (فارسی + انگلیسی) اینجاست
```

## ۳. چطور متن‌های سایت را تغییر دهم؟

تقریباً همهٔ متن‌های قابل‌مشاهده در سایت (چه فارسی چه انگلیسی) در یک فایل جمع شده‌اند:

**`src/contexts/LanguageContext.tsx`**

این فایل دو بخش بزرگ دارد:
- بخش اول: ترجمه‌های انگلیسی (`en: { ... }`)
- بخش دوم: ترجمه‌های فارسی (`fa: { ... }`)

هر متن یک «کلید» دارد، مثلاً:

```ts
'hero.subtitle': 'متن زیرعنوان بخش اصلی اینجاست',
```

کافی‌ست کلید موردنظر را در بخش فارسی (و در صورت نیاز انگلیسی) پیدا کرده و
مقدار بعد از `:` را تغییر دهید. نیازی به تغییر جای دیگری نیست — چون تمام
کامپوننت‌ها متن را از همین فایل با تابع `t('کلید')` می‌خوانند.

نمونهٔ کلیدهای مهم:
| کلید | مربوط به |
|---|---|
| `hero.badge`, `hero.subtitle` | بخش اصلی (Hero) |
| `about.description` | معرفی شخصی در بخش «درباره من» |
| `skills.*` | مهارت‌های نمایش داده‌شده در «درباره من» |
| `services.*` | خدمات در بخش «خدمات» |
| `caseStudies.*` | مطالعات موردی |
| `form.*` | فرم «شروع همکاری» |
| `reviews.*` | فرم و بخش «نظرات و پیشنهادات» |
| `ai.*` | متن‌های ویجت چت‌بات هوش مصنوعی |

## ۴. چطور رنگ‌های سایت را تغییر دهم؟

فایل: `src/styles.css`

رنگ‌ها به‌صورت متغیرهای CSS در دو بخش تعریف شده‌اند:

- `:root { ... }` → رنگ‌های **تم روشن**
- `.dark { ... }` → رنگ‌های **تم تیره**

مهم‌ترین متغیرها:
- `--primary` → رنگ اصلی (آبی)
- `--accent` / `--cyan` → رنگ فیروزه‌ای مکمل
- `--background` / `--foreground` → رنگ پس‌زمینه و متن اصلی

رنگ‌ها با فرمت `oklch(...)` نوشته شده‌اند. اگر با این فرمت راحت نیستید،
می‌توانید هر ابزار آنلاین تبدیل رنگ (مثل [oklch.com](https://oklch.com)) را
باز کرده، رنگ دلخواه را انتخاب و مقدار oklch آن را جایگزین کنید.

## ۵. تم روشن/تیره

سایت اکنون یک دکمهٔ تغییر تم در نوار بالای صفحه دارد
(کامپوننت `src/components/sections/ThemeToggle.tsx`). تم انتخابی کاربر در
مرورگر او (`localStorage`) ذخیره می‌شود و در بازدید بعدی حفظ می‌شود.
تم پیش‌فرض سایت (وقتی کاربر هنوز انتخابی نکرده) در
`src/components/PortfolioApp.tsx` با `defaultTheme="dark"` تنظیم شده — در صورت تمایل
می‌توانید آن را به `"light"` تغییر دهید.

## ۶. متغیرهای محیطی (Environment Variables)

برای فعال‌سازی چت‌بات هوش مصنوعی و اتصال فرم‌ها به تلگرام، باید یک فایل `.env`
در ریشهٔ پروژه بسازید (فایل `.env.example` را کپی کرده و به `.env` تغییر نام دهید)
و مقادیر لازم را پر کنید. جزئیات کامل هر متغیر داخل همان فایل `.env.example`
با توضیح فارسی نوشته شده. خلاصه:

```
VITE_AI_API_ENDPOINT=...     # آدرس API هوش مصنوعی
VITE_AI_API_KEY=...          # کلید API (اختیاری، بسته به سرویس)
VITE_TELEGRAM_BOT_TOKEN=...  # توکن بات تلگرام
VITE_TELEGRAM_CHAT_ID=...    # آیدی چت مقصد در تلگرام
```

⚠️ **نکتهٔ امنیتی:** چون این سایت یک اپلیکیشن سمت مرورگر (client-side) است،
هر مقداری که در `.env` بگذارید نهایتاً در کد قابل‌مشاهده توسط کاربر قرار می‌گیرد.
برای استفادهٔ کاملاً امن در آینده (به‌خصوص کلید API هوش مصنوعی)، پیشنهاد می‌شود
یک بک‌اند کوچک یا Serverless Function بسازید که این درخواست‌ها را پروکسی کند و
کلیدها را فقط سمت سرور نگه دارد. ساختار فعلی برای شروع سریع و تست کاملاً مناسب است.

## ۷. ویجت چت‌بات هوش مصنوعی

فایل‌های مرتبط:
- `src/components/sections/AIChatWidget.tsx` → رابط کاربری (دکمهٔ شناور + پنجرهٔ چت)
- `src/lib/ai-assistant.ts` → منطق اتصال به API خارجی

بعد از پر کردن `VITE_AI_API_ENDPOINT` در فایل `.env`، ویجت به‌صورت خودکار فعال
می‌شود. اگر ساختار پاسخ API شما با ساختار پیش‌فرض (`{ reply: "..." }`) فرق دارد،
کافی‌ست تابع `sendAIMessage` در فایل `src/lib/ai-assistant.ts` را باز کرده و
خط مربوط به خواندن پاسخ را با ساختار API خودتان هماهنگ کنید.

---

## ۸. اتصال فرم‌ها به تلگرام

فایل: `src/lib/telegram.ts`

دو فرم سایت («شروع همکاری» در `StartWorking.tsx` و «نظر یا پیشنهاد» در
`Reviews.tsx`) طوری آماده شده‌اند که هنگام ثبت موفق، خلاصه‌ای از پیام را به
تابع `sendToTelegram` می‌فرستند. تا وقتی `VITE_TELEGRAM_BOT_TOKEN` و
`VITE_TELEGRAM_CHAT_ID` را در `.env` پر نکرده باشید، این تابع فقط در کنسول
مرورگر لاگ می‌کند و خطایی برای کاربر ایجاد نمی‌شود. بعد از پر کردن این دو
مقدار، پیام‌ها به‌صورت خودکار به بات تلگرام شما ارسال می‌شوند.

## ۱۰. امکانات تازه (ترمینال، مسیر زمانی، دموهای زنده، شوخی مخفی)

- **ترمینال تعاملی** (`src/components/sections/Terminal.tsx`): یک ترمینال شبیه‌سازی‌شده که کاربر می‌تواند
  دستورات (`help`, `whoami`, `skills`, `projects`, `contact`, `demo`, `theme`, `sudo hire-me`, `patrick`, `clear`)
  را در آن اجرا کند. برای افزودن دستور جدید، یک `case` تازه به `switch` داخل تابع `runCommand` اضافه کنید.
- **مسیر زمانی (Timeline)** (`src/components/sections/Timeline.tsx`): مراحل مسیر شغلی/یادگیری با اسکرول پر می‌شود.
  برای تغییر مراحل، آرایهٔ `steps` در همین فایل و کلیدهای `timeline.step1` تا `timeline.step5` در
  `LanguageContext.tsx` را ویرایش کنید.
- **دموهای زنده** (`src/components/sections/LiveDemos.tsx`): دو پروژهٔ نمونه از گیت‌هاب پیجز شما را با کلیک
  به‌صورت iframe زنده نمایش می‌دهد (تا وقتی کلیک نشود، iframe لود نمی‌شود تا سرعت سایت افت نکند).
  برای افزودن دموی جدید، یک آیتم به آرایهٔ `demos` اضافه و کلیدهای ترجمهٔ متناظر را در `LanguageContext.tsx` بسازید.
- **شوخی مخفی (Easter Egg)** (`src/components/EasterEgg.tsx` + `src/hooks/useKonamiCode.ts`): با وارد کردن
  دنبالهٔ کلاسیک Konami Code (بالا بالا پایین پایین چپ راست چپ راست B A) یک باران آناناس نمایش داده می‌شود.
- **پیش‌بارگذار (Preloader)** (`src/components/Preloader.tsx`): یک بار در هر session، قبل از نمایش سایت
  یک انیمیشن ورود کوتاه نشان می‌دهد.
- **گذار نرم تم روشن/تیره**: تغییر تم با افکت دایره‌ای از نقطهٔ کلیک دکمه انجام می‌شود (با View Transition API؛
  در مرورگرهای قدیمی‌تر به‌صورت معمولی و بدون افکت خاص انجام می‌شود).
- **اسکرول نرم Lenis** (`src/hooks/useLenisScroll.ts`): کل سایت از اسکرول نرم و لغزان استفاده می‌کند. اگر
  باکسی داخل سایت نیاز به اسکرول مستقل خودش دارد (مثل خروجی ترمینال)، باید `data-lenis-prevent` روی آن باشد.

## ۱۱. اجرا و انتشار

**اجرای محلی (برای دیدن و ویرایش سایت):**

```sh
npm install
npm run dev
```

بعد `http://localhost:8080` را در مرورگر باز کنید (پورت ۸۰۸۰ است).

**اجرای نسخهٔ نهایی روی کامپیوتر یا سرور (Node.js ≥ 20.19):**

```sh
npm install
npm run build:node
npm start
```

سایت روی `http://localhost:3000` بالا می‌آید (پورت را با متغیر `PORT` می‌توانید عوض کنید). اگر `TELEGRAM_BOT_TOKEN` و
`TELEGRAM_CHAT_ID` را در فایل `.env` گذاشته‌اید، به‌جای `npm start` از `npm run start:env` استفاده کنید تا `.env` خوانده شود
(روی هاست‌ها همین دو مقدار را در بخش Environment Variables پنل هاست وارد کنید).

**انتشار روی Cloudflare / Lovable:** همان `npm run build` پیش‌فرض (خروجی Cloudflare Worker) را استفاده کنید.

### آیدی تلگرام و بخش «همکاری»

- آیدی تلگرام فقط در `src/config/contact.ts` (مقدار `TELEGRAM_USERNAME`) تنظیم می‌شود و همه‌جای سایت از همان می‌آید.
- اگر ربات تلگرام تنظیم نشده باشد، فرم «همکاری» متن را کپی می‌کند و یک پنل با دکمه‌های «باز کردن تلگرام / ارسال با ایمیل / کپی دوباره» نشان می‌دهد.
  برای ارسال مستقیم، `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` را روی سرور تنظیم کنید (بخش ۸).

### افزودن پروژهٔ جدید

- پروژهٔ برجسته: یک آیتم به `src/data/projects.ts` اضافه کنید.
- دمو: یک آیتم به `src/data/demos.ts` اضافه کنید (`kind: 'app'` برای اپ منتشرشده که در تب جدید باز می‌شود).
- شبیه‌سازهای تعاملی NetScope و SecureSync در `src/components/sections/Simulations.tsx` هستند و زیر دموهای زنده نمایش داده می‌شوند.
- فایل `public/og-image.png` تصویر پیش‌نمایش لینک (تلگرام، لینکدین، توییتر) است؛ پس از انتشار، آدرس کامل دامنه را در `src/routes/index.tsx` برای `og:image` بگذارید.

## ۱۲. یادداشت‌های کدنویسی داخل فایل‌ها

در سراسر کد، کامنت‌های فارسی گذاشته شده تا هر تابع، متغیر و بخش مهم توضیح
داده شود. اگر به دنبال جایی خاص می‌گردید، از جستجوی سراسری (Ctrl+Shift+F در
VS Code) روی متن فارسی مرتبط استفاده کنید — معمولاً سریع‌تر از گشتن دستی است.
